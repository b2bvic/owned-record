# cc-bridge

A zero-dependency converter from local transcript records to daily Markdown logs.

## Principle cluster

This repository demonstrates **P02 (own the memory plane)** and **P03 (continuity compounds)** because it incrementally parses new JSONL records and writes only complete exchanges.

[Read the principles](https://victorvalentineromo.com/principles).

## Worked example

```bash
./cc-bridge
```
